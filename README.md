# java-console-calculator
A simple menu-driven console calculator built in Java using Scanner, switch-case, loops, and basic arithmetic operations. This project demonstrates core Java programming concepts and user input handling.
## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Menu-driven interface
- Continuous execution until Exit
## Technologies Used
- Java
- VS Code
## How to Run

1. Compile the program:
   ```
   javac Calculator.java
   ```

2. Run the program:
   ```
   java Calculator
   ```
